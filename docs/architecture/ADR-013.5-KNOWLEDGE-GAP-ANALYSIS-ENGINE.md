# ADR-013.5 — Knowledge Gap Analysis Engine

## Status

Accepted

## Date

2026-07-23

---

# Context

Global Career AI V1.0 requires the ability to identify knowledge deficiencies
inside a candidate knowledge profile and transform those deficiencies into
actionable learning recommendations.

Previous Knowledge Intelligence components established:

- Knowledge Domain Intelligence
- Domain Scoring Strategy
- Knowledge Domain Hierarchy

However, the system required a decision layer capable of analyzing the
difference between current competency knowledge and desired knowledge levels.

---

# Problem

Without a dedicated Knowledge Gap Analysis Engine, the platform could:

- identify knowledge scores,
- evaluate domains,
- calculate competency levels,

but could not determine:

- which competencies require improvement,
- the importance of each gap,
- learning priorities,
- estimated improvement impact.

A dedicated analysis layer was required.

---

# Decision

Implement the Knowledge Gap Analysis Engine as part of the Knowledge
Intelligence Layer.

The engine receives:

- Knowledge Profile
- Domain Evaluation Results

and produces:

- Strengths
- Weaknesses
- Competency Gaps
- Learning Priorities
- Learning Recommendations
- Improvement Estimates

---

# Scoring Strategy

The engine separates scoring dimensions:

## Internal Gap Calculation

Range:


0 - 100


Used for:

- gap magnitude
- priority calculation
- impact estimation


## Improvement Projection

Normalized range:


0 - 1


Used for:

- API responses
- profile analytics
- future learning optimization

ADR-013.5.1 defines the normalization boundary.
