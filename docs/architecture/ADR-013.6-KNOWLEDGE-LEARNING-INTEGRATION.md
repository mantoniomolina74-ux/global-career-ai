# ADR-013.6 — Knowledge Learning Integration

## Status

Accepted

## Date

2026-07-24

---

# Context

Global Career AI V1.0 incorpora un sistema de Knowledge Intelligence
capaz de analizar el conocimiento profesional de un usuario mediante:

- evaluación de competencias;
- clasificación por dominios;
- análisis de brechas;
- generación de recomendaciones de aprendizaje.

Antes de este ADR, el módulo Knowledge funcionaba como un sistema
analítico independiente:
Professional Text
|
v
Knowledge Profile Analysis
|
v
Knowledge Gap Analysis
|
v
Learning Recommendations


Sin embargo, los resultados generados por Knowledge Intelligence
no participaban todavía en el sistema de aprendizaje global.

Era necesario conectar Knowledge con el Learning System sin romper:

- compatibilidad existente;
- separación de responsabilidades;
- arquitectura Clean Architecture.

---

# Decision

Se implementa un adaptador entre Knowledge Intelligence y Learning System.

La integración utiliza el patrón:


Knowledge Layer
|
v
Knowledge Learning Adapter
|
v
Learning Domain Event
|
v
Learning Event Bus
|
v
Learning Memory


La integración es opcional mediante contexto de usuario.

El análisis continúa funcionando sin usuario:

```ts
analyzeKnowledgeProfile(
  professionalText
)

Cuando existe identidad:

analyzeKnowledgeProfile(
  professionalText,
  {
    userId
  }
)

se genera un evento de aprendizaje.

Architectural Principle

Knowledge Intelligence no conoce detalles internos del Learning System.

No interactúa directamente con:

Learning Memory;
EventEmitter;
consumidores;
persistencia.

Solamente comunica mediante:

emitLearning(event)

Esto mantiene:

bajo acoplamiento;
evolución independiente;
separación de dominios.
Implementation
Learning Event Extension

Archivo:

lib/engine/learning/learningTypes.ts

Se agregó soporte para:

metadata.source = "KNOWLEDGE"

El sistema ahora reconoce eventos originados desde:

ATS;
Ranking;
Recommendation;
Decision;
Orchestrator;
Knowledge.
Knowledge Learning Adapter

Archivo:

lib/knowledge/adapters/knowledgeLearningAdapter.ts

Responsabilidad:

Transformar:

KnowledgeGapResult

en:

LearningDomainEvent
Event Structure

El evento generado contiene:

{
  userId,

  type: "LEARNING_EVENT",

  context: {
    action: "KNOWLEDGE_GAP_ANALYSIS",

    matchedSkills,

    missingSkills
  },

  payload: {

    knowledgeAnalysis: {

      totalGaps,

      currentScore,

      projectedScore,

      improvement,

      gaps,

      priorities,

      recommendations

    }

  },

  metadata: {

    source: "KNOWLEDGE"

  }
}
Payload Design Decision

El payload utiliza una sección dedicada:

payload.knowledgeAnalysis

en lugar de mezclar propiedades directamente.

Razón:

Permite futuras extensiones:

payload: {

  knowledgeAnalysis: {},

  careerTrajectory: {},

  skillEvolution: {}

}

manteniendo separación semántica.

Knowledge Profile Service Integration

Archivo:

lib/knowledge/services/knowledgeProfileService.ts

El servicio ahora acepta contexto opcional:

options?: {
  userId?: string;
}

 text,

   userId
 }

Consequences
Positive
Knowledge Intelligence ahora alimenta el sistema de aprendizaje.
Las brechas profesionales pueden convertirse en memoria evolutiva.
Las recomendaciones pueden evaluarse posteriormente.
Se habilita aprendizaje longitudinal del usuario.
Trade-offs
Los eventos Knowledge requieren contexto de usuario para generar memoria.
La calidad del aprendizaje depende de la precisión del Knowledge Gap Analysis.
Future Evolution

Esta integración prepara futuras capacidades:

Learning Path Engine.
Career Growth Tracking.
Skill Evolution Timeline.
Personalized Upskilling Recommendations.
Knowledge-based Career Decisions.

        |

ADR Decision

Accepted.

Knowledge Intelligence queda integrado al Learning System mediante eventos
de dominio opcionales basados en contexto de usuario, manteniendo
compatibilidad V1.0 y preparando evolución futura.
